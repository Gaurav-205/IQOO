# Security & Data Privacy Policy

## Core Architecture: Zero-Cloud Privacy Model

**Visible** is built on a **Zero-Cloud Financial Privacy** guarantee:
1. **100% On-Device NPU Execution**: All econometric analysis and credit-readiness scoring are performed locally on the smartphone's neural engine.
2. **Zero Permanent Server Storage**: Raw bank transaction data, OCR document captures, and account details never leave the user's phone.
3. **Timebound RBI Account Aggregator Consent**: Consent tokens expire automatically in 90 days and can be revoked instantly at any time from the in-app Privacy Control Center.
4. **1-Tap Cache Erasure**: Users can permanently wipe all locally cached financial records with one tap.

## Reporting Security Vulnerabilities

If you discover a potential security vulnerability or issue with cryptographic token handling, please do not open a public issue. Instead, report details to `security@visible-fintech.dev` or reach out via our GitHub repository security advisories tab.
